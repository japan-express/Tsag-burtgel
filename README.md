# Цаг бүртгэлийн апп — суулгах заавар

1. https://supabase.com дээр үнэгүй төсөл үүсгэнэ.
2. SQL Editor → `schema.sql`-ийн агуулгыг буулгаж Run.
3. Authentication → Users → "Add user": ажилтан бүрт имэйл + нууц үг үүсгэнэ
   (User Metadata-д `{"name":"Бат"}` гэж өгвөл нэр нь харагдана).
   Authentication → Providers → Email дээр "Confirm email"-ийг унтраавал хялбар.
4. Өөрийгөө админ болгох: schema.sql-ийн доод талын `update profiles ...` мөрийг имэйлээ солиод ажиллуулна.
5. `index.html` дотор SUPABASE_URL, SUPABASE_KEY (anon public key)-ээ бөглөнө.
6. `index.html`-ийг Netlify Drop (app.netlify.com/drop), Vercel эсвэл GitHub Pages дээр байршуулна — HTTPS холбоос гарна.
7. Админаар нэвтэрч "Админ" таб дахь QR-г хэвлэнэ. Ажилтан камераар уншуулж → нэвтэрсэн бол нэг товшоод бүртгүүлнэ.
8. Холбоосыг ажилтнуудад илгээгээд утасны "Нүүр дэлгэцэнд нэмэх" гэж хэлнэ.

Аюулгүй байдал: цагийг сервер тэмдэглэнэ, ажилтан зөвхөн өөрийнхөө бүртгэлийг харна, админ бүгдийг харна (RLS).
